# Writing, rewrite and set-up panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A writing task (IELTS Task 2 essay), a rewrite task, errors per 100 words, a Writing page, errors-without-topic in the error bank, and the lesson picker redone as a set-up panel behind a gear on the Start button.

**Architecture:** Writing blocks are ordinary `block` rows (kind `writing`, format `essay` / `rewrite`). The essay prompt comes from the existing generate call; the rewrite block is built by the app. On "Check" the existing grade call gets a "Texts" section; every error it returns becomes an `item` + `answer` (verdict `wrong`), so the error bank, review, disputes and recomputation work unchanged. The text itself goes to a new `writing_text` table.

**Tech Stack:** Tauri + React 19 + TypeScript, Tailwind 4 + shadcn tokens, SQLite (migrations in `src/db/migrations`), Vitest, Playwright preview mode (`/?state=<fixture>#/route`), Yarn 4.

**Spec:** `docs/superpowers/specs/2026-11-02-writing-design.md` (W1–W9). Background: `docs/superpowers/specs/2026-11-02-lesson-picker-design.md`, `docs/superpowers/handoff.md`.

## Global Constraints
- Every user-visible string in both `src/core/i18n/ru.ts` and `src/core/i18n/en.ts`; short sentences; no em dashes in UI strings.
- Icons: lucide, `strokeWidth={1.5}`, `aria-hidden`.
- No new dependencies.
- Words are counted by splitting on whitespace. `MIN_WORDS = 50`, `TARGET_WORDS = 250`, rate target 3.
- `rate = counted errors / words × 100`, one decimal.
- Light days never include writing or rewrite.
- Commands (prefix with `COREPACK_NPM_REGISTRY=https://registry.npmjs.org NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt` if yarn cannot download itself): `yarn typecheck`, `yarn lint`, `yarn test`, `yarn e2e`. Known: `tests/e2e/csp.spec.ts` fails in this container (HMR websocket); ignore it.
- Commit trailer of the implementing model on every commit.

## Review Focus
1. **Existing databases:** migration 0005 rebuilds `block`; existing blocks, items, answers, spot answers and extra findings must survive with the same ids (Task 1 test).
2. **A fragment the grader returns that is not in the text** must not be stored; the call is retried with a check message (Task 5 test).
3. **An added round with only a writing block** must re-open grading even though the block has no items (Task 5 test on `hasOpenItems`).
4. **Old stored choices** (`session.choice` without `writing`/`rewrite`) must rebuild without crashing (Task 3 test).
5. **Writing items must not create a block score** ("N of M") in the progress log, while still counting in the error bank (Task 6 test).
