# Design: words (vocabulary practice) (2026-11-04)

S2's vocabulary part: a word store, import from Obsidian, generated exercises, a Words page with a practice screen, and progress per word (stages + FSRS). This spec is binding where it says something. Where it says nothing, the S1 spec, its rounds and the writing spec still hold. Agreed with the learner in chat on 2026-11-04. It supersedes D10 ("learner enters vocabulary manually"): words are imported once from Obsidian and are also added by hand. Out of scope here: preposition deck, exports, ⌘K, audio, Obsidian sync or export, PWA/mobile and sync between devices (a later stage).

## V1. Word data
- **Fields** (taken from the learner's Obsidian card): `definition`, `translation` (native language), `word`, `example`, `synonyms` (list), `link`, `added` (date).
- `word` is required and unique (case-insensitive). The learner fills what they can. The `words` call (V3) fills the empty `definition`, `translation`, `example` and `synonyms`. All fields stay editable.
- **`link`** is never generated by the LLM. It opens in the system browser through the Tauri opener plugin; its permission allows `https://` URLs only (a security addition to round 1, agreed with the learner). When `link` is empty or not an `https://` link, the app shows the code-built Oxford search link `https://www.oxfordlearnersdictionaries.com/search/english/?q=<word>`.
- `added` = the date from the card, or today for a word added by hand.
- Generated English follows the `spelling_variant` setting.

## V2. Import from Obsidian (paste)
- An "Импорт" / "Import" inline panel with a textarea. The learner pastes Markdown from Obsidian. No file access is needed, so P4 is unchanged.
- **Parser** (code, no LLM). A card:
  - starts at a `### ` heading. The heading text is the definition; a trailing `(…)` is the translation and is removed from the definition;
  - is followed by a line with only `?`;
  - has field lines `**Word:**`, `**Example:**` (surrounding quotes removed), `**Synonyms:**` (comma-separated), `**Link:**` and `**Added:**` (`DD.MM.YYYY`).
  - The `<!--SR:…-->` line and any other lines are ignored. Words start with their own progress (V5).
- **Preview** before import: "Найдено N · K уже есть · M проблем" / "Found N · K already exist · M problems", with each problem named (for example "карточка 14: нет Word" / "card 14: no Word").
  - Duplicates (already stored, or twice in the paste) and cards with no `Word` are skipped.
  - "Импортировать N слов" / "Import N words" saves the words and starts generation (V3).

## V3. Generation (the `words` call, once per word)
- **New call kind `words`**, with its own model and effort row in Settings, a prompt `prompts/words.md` and a schema `prompts/words.schema.json`.
- **Batches** of up to 5 words per call (300 s timeout). They run in the background through a words job provider (modelled on GenerationProvider), so they survive leaving the page; the core job lock is taken per batch, so a lesson waits at most one batch. Example: 90 imported words take 18 calls.
- **Input per word:** the learner's fields (empty fields marked as missing), the native language and the spelling variant.
- **Output per word:**
  - the missing fields (`definition`, `translation`, `example`, `synonyms`); the learner's text is never overwritten;
  - `gaps`: 3–5 sentences (not the stored example), each with the word replaced by `___`, the accepted answer (the form that fits the sentence, for example `superseded`) and the sentence's translation;
  - `collocations`: 2–3, each a phrase with a gap plus the accepted answer (for example "ensure full ___" → `compliance`);
  - `forms`: 0–3, each a sentence that needs another form of the word family, the base form shown as a cue, and the accepted answer (empty when the word has no useful family);
  - `confusables`: 0–2, each a sentence, 2–3 options (the word and near-synonyms), the correct option and a one-line reason;
  - `translations`: 2 native-language passages (1–3 sentences each) that need the word, each with 2–4 accepted English answers.
- **Validation** (code, like the other call kinds): counts as above; every `___` occurs exactly once; answers are non-empty; schema check. (No stem check: irregular and phrasal forms must pass.) A word that fails validation, or whose batch fails, is marked "Упражнения не созданы" / "Exercises not created" with "Повторить" / "Retry" in the list. Words without exercises are never offered in practice.
- **Regenerate** (on a word's details) replaces its exercises. Its review history is kept.
- Code-built (not generated): the **anagram** (the letters of `word` shuffled, never in the original order) and the **choice** options (V4).

## V4. Exercises by stage
| Stage | Exercises |
|---|---|
| 1 · Новое / New | anagram + definition; gap **with** the sentence's translation |
| 2 · Вспоминание / Recall | gap **without** the translation; collocation; word form; confusable |
| 3 · Употребление / Use | translation (native → English); "use it" |
| ✓ Выучено / Learned | a random exercise from stages 2 and 3 |

- **Choice** (the definition plus 4 options; the other options are the learner's other words): only on a word's **very first** card, never after (the learner finds it too easy to guess).
- The exercise type is picked at random from the stage. Within a type, the item used least recently comes first.
- **Use it:** "Напишите предложение со словом «X»" / "Write a sentence with "X"", with a textarea, "Пропустить" / "Skip" and "Проверить" / "Check". A skipped card is not recorded. Skip replaces the card right away with a translation card of the same word if one exists; otherwise practice moves on.

## V5. Progress: stages and FSRS
- **One FSRS card per word**, using the `ts-fsrs` library (MIT): default parameters, desired retention 0.90, `enable_short_term: false` (intervals in whole days), fuzz on.
- **Rating from the result** (no self-rating buttons):
  - wrong → *Again*;
  - correct after the first-letter hint or after an "Almost" retry → *Hard*;
  - correct → *Good*.
- **Stage:**
  - 2 correct counted answers in the current stage, on **different days**, move the word up one stage;
  - a wrong counted answer moves it down one stage (not below New) and resets that stage's count;
  - **Learned** = stage 3 passed and the FSRS interval is at least 21 days;
  - a wrong answer on a Learned word moves it back to Use.
- **Counted answer:** only the first answer to a word on a calendar day counts for FSRS and the stage. Later answers that day are recorded but not counted.
- **Derived, never stored** (as D18): the stage and the FSRS state are replayed from `word_review` in order. A pure function, unit-tested.

## V6. Checking answers
- **Typed answers** (anagram, gap, collocation, form): trimmed and case-insensitive exact match against the accepted answers.
- **"Almost"** (Levenshtein distance 1 to an accepted answer): "Почти — одна буква не та. Попробуйте ещё раз." / "Almost — one letter is off. Try again." This is allowed once per card: a correct retry counts as *Hard*, and a second miss is wrong.
- **First-letter hint button:** the first letter appears in the field, and a correct answer counts as *Hard*. The anagram and the choice have no hint.
- **Confusable and choice:** a click on an option, correct or wrong.
- **Translation:** an exact match against an accepted answer (the same normalising, plus final punctuation ignored) is correct. Otherwise the accepted answers are shown with "Я ответил(а) верно" / "I was right" and "Я ошибся(лась)" / "I was wrong" (Good or Again). No LLM.
- **Use it: new call kind `word_check`**, with its own Settings row, prompt and schema. It returns:
  - `wordOk`: whether the word is used correctly in meaning, form and collocation;
  - `wordNote`: a short note in the native language;
  - `errors`: other mistakes in the sentence, in the writing format (`fragment`, `fix`, `topicKey`, `suggestedTopic`, `ruleSection`, `explanation`).
  - The rating comes from `wordOk`: Good or Again.
  - If the call fails: an inline error with "Повторить" / "Retry". The learner can also Skip.

## V7. "Use it" mistakes in the error bank
- Each `errors` entry from `word_check` is stored in a new table `word_error`. The error bank lists these entries together with the session errors:
  - was = fragment, should be = fix;
  - topic, or "Другое" / "Other" with the possible topic (as W7);
  - date = the practice date;
  - a muted source label "Слова" / "Words".
- In this version they are **not** disputable and are **not** added to the lesson's review.

## V8. Practice
- **Size:** 20 cards. At the end: "Продолжить · ещё 20" / "Continue · 20 more" if more cards are available.
- **Queue:** due words first (FSRS due ≤ today, the most overdue first), then new words (never reviewed, oldest `added` first) up to **10 new words per day**. A word appears at most once in the 20, except for one repeat: a word answered wrong comes back once at the end of the same practice. The repeat is recorded but not counted (V5).
- **One card at a time:** ↵ checks, and ↵ again goes to the next card.
- **Feedback** after each card: ✓ / ✗ with the learner's answer, the word, the translation, the definition, the example and the link (opens in the browser), plus the `wordNote` and errors for "use it".
- **Header:** "7 / 20" and a ghost "Закончить" / "End".
- **End screen:** "Готово: 16 из 20" / "Done: 16 of 20 correct", "Повысились" / "Moved up" (word → stage) and "Понизились" / "Moved down", then "К словам" / "Back to words" and "Продолжить · ещё 20" / "Continue · 20 more".
- Each answer is saved as soon as it is checked, so leaving in the middle loses nothing.
- If nothing is due and no new word is left: "На сегодня всё. Следующее повторение: <date>" / "All done for today. Next review: <date>".

## V9. Words page
- Sidebar item "Слова" / "Words" (lucide `book-a`), after Writing. It was hidden until S2.
- **Header:** counts per stage, "К повторению сегодня: N" / "Due today: N", and the primary "Начать практику" / "Start practice" button (disabled with `not-allowed` when there is nothing to practise).
- **Toolbar:** "Добавить слово" / "Add word" (an inline form with the V1 fields; only `word` is required; saving starts a `words` call for that word), "Импорт" / "Import" (V2) and a search field over word, translation and definition.
- **List:** word, translation, stage chip, next review date (or "новое" / "new"), and the generation status when exercises are pending or failed.
- **Details** (a row expands inline):
  - all fields, editable;
  - the exercises, editable per item: text and accepted answers;
  - "Создать заново" / "Regenerate" and "Удалить" / "Delete" (deleting asks for inline confirmation and removes the word, its exercises, its reviews and its `word_error` rows).
- **Today:** when at least one word is due or new, one line is shown under the lesson header: "Слова: N к практике → Практика" / "Words: N to practise → Practise" (N = due + new words allowed today), linking to the Words page.
- **Pointer cursor** on every clickable element, including options, list rows and anagram letters if they are clickable (CLAUDE.md). `tests/e2e/cursor.spec.ts` gets cases for the Words page, the import panel and the practice states.

## V10. Storage (migration 0006)
- `word`: id, word (unique, case-insensitive), definition, translation, example, synonyms (JSON), link, added, generation (`pending` / `ready` / `failed`), created_at.
- `word_exercise`: id, word_id (ON DELETE CASCADE), type (`gap` / `collocation` / `form` / `confusable` / `translation`), prompt, translation (gap only), cue (form only), options (JSON, confusable only), answers (JSON), note (confusable reason).
- `word_review`: id, word_id (cascade), exercise_type (the card type, incl. `anagram`, `choice`, `gap_hint`, `use`; no CHECK), exercise_id (nullable), answered_at, date, result (`correct` / `hard` / `wrong`), counted (bool), text.
- `word_error`: id, review_id (cascade), fragment, fix, topic_id (nullable), suggested_topic, rule_section, explanation.
- `settings`: the `models` and `efforts` JSON entries gain `words` and `word_check`.

## V11. Testing
- **Vitest:**
  - parser (sample cards, translation in the heading, quotes, missing fields, the SR line, duplicates);
  - generation validation;
  - stage + FSRS replay (move up on different days, the same-day rule, move down, Learned at 21 days, back from Learned);
  - queue (due order, new limit, 20 cards, the wrong-answer repeat);
  - checking (normalising, Almost, hint → Hard, translation match);
  - anagram never in the original order.
- **E2E (preview states `words`, `words-practice`, `words-done`):** import preview and import; add a word; practice through each exercise type; Almost and retry; translation self-mark; use it with Skip and Check; end screen; the Today link; the error bank shows a Words error; pointer cursor.
- **Evals:** add cases for `words` (field filling, valid gaps and forms) and `word_check`.
